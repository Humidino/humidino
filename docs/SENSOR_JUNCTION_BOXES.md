# Датчики через две распредкоробки

Проверено по include/config.h и src/sensors.cpp 7 сентября 2026 г.
Основная электрическая инструкция: [WIRING.md, раздел 3](WIRING.md).
Питание щитка: [PANEL_WIRING.md](PANEL_WIRING.md).

**Исправление прежней версии:** восемь сигналов в одном UTP без парных
проводов GND и выдуманные «жёлтые/фиолетовые» цвета UTP больше не рекомендуются.
Предложенная ниже разводка требует больше жил. Уже проложенный кабель
не считать автоматически соответствующим этой таблице: сначала определить
его реальные жилы и длину. Физическая топология двух коробок сохраняется.

## 1. Топология и пины

~~~text
Щит ── участок A ── коробка №1 ──┬── Приточка
                               ├── Середина
                               └── участок B ── коробка №2 ──┬── Дальний угол
                                                            └── Улица
~~~

У каждой зоны своя SDA/SCL; общими являются 3,3 V и GND.

| Датчик | Шина | SDA / клемма | SCL / клемма |
|---|---|---|---|
| Приточка | I2C0, Wire | GPIO21 / Низ №5 | GPIO18 / Верх №12 |
| Середина | I2C2, SoftI2C | GPIO4 / Верх №19 | GPIO5 / Верх №18 |
| Дальний угол | I2C3, SoftI2C | GPIO6 / Верх №17 | GPIO7 / Верх №16 |
| Улица | I2C1, Wire1 | GPIO47 / Низ №6 | GPIO8 / Верх №11 |

VDD — 3V3 (Верх №21/22), GND — любая клемма GND. Номера клемм применимы
только к переходнику YD-ESP32-S3 44P из WIRING.md. Для иной ESP32-S3-N16R8
ориентироваться на GPIO и паспорт её платы, а не положение винта.
Все датчики — 0x44, ADDR→GND на самом модуле. Заводскую распайку
герметичного датчика проверять по его документации, а не по цветам из этого файла.

## 2. Кабели и реальные цвета UTP

Участок A: **два UTP по четыре пары + отдельный двухжильный кабель питания**.
Это 16 жил UTP и 2 жилы питания. На каждый из восьми сигналов выделена
своя пара «сигнал/GND». Кабели маркируются A1 и A2.

Участок B: **один UTP по четыре пары + отдельный двухжильный кабель питания**.
Это 8 жил UTP и 2 жилы питания. UTP маркируется B1.

Прежние «10 жил A / 6 жил B» — лишь минимальное число электрических цепей
без парных возвратных проводов; они не реализуют эту раскладку UTP.
Если именно такие кабели уже смонтированы, нужна отдельная оценка
их пригодности по длине, ёмкости и измерениям сигналов.

| Кабель | Пара | Цветная жила | Бело-цветная жила |
|---|---|---|---|
| A1 | Оранжевая | SDA0, GPIO21 | GND |
| A1 | Зелёная | SCL0, GPIO18 | GND |
| A1 | Синяя | SDA2, GPIO4 | GND |
| A1 | Коричневая | SCL2, GPIO5 | GND |
| A2 | Оранжевая | SDA3, GPIO6 | GND |
| A2 | Зелёная | SCL3, GPIO7 | GND |
| A2 | Синяя | SDA1, GPIO47 | GND |
| A2 | Коричневая | SCL1, GPIO8 | GND |
| B1 | Оранжевая | SDA3, продолжение A2 | GND |
| B1 | Зелёная | SCL3, продолжение A2 | GND |
| B1 | Синяя | SDA1, продолжение A2 | GND |
| B1 | Коричневая | SCL1, продолжение A2 | GND |

Отдельные кабели питания на обоих участках: жила с меткой «3V3» и жила
с меткой «GND». Сечение выбрать по длине и падению напряжения.
Все бело-цветные жилы UTP — GND, подключаются на обоих концах, в том числе
в коробках. Объединять их через подходящие клеммы с достаточным числом портов.
Это общая земля электроники; **PE для неё не требуется, с сетевым N её не соединять**.

Сигнальные цветные жилы разных шин не соединять между собой.
Не использовать этот кабель как Ethernet и не включать его в сетевое оборудование.

## 3. Коробка №1

| Цепь | Соединение |
|---|---|
| Питание 3V3 участка A | К VDD Приточки, VDD Середины и питанию 3V3 участка B |
| GND участка A | К GND обоих датчиков, всем возвратным жилам и GND участка B |
| A1 оранжевый | Только SDA Приточки |
| A1 зелёный | Только SCL Приточки |
| A1 синий | Только SDA Середины |
| A1 коричневый | Только SCL Середины |
| A2 оранжевый | B1 оранжевый, SDA Дальнего угла |
| A2 зелёный | B1 зелёный, SCL Дальнего угла |
| A2 синий | B1 синий, SDA Улицы |
| A2 коричневый | B1 коричневый, SCL Улицы |

У A2→B1 четыре отдельных сигнальных соединения. Сигналы A1 здесь
заканчиваются отводами на два ближних датчика и в B1 не идут.

## 4. Коробка №2 и отводы

| Цепь B1 | Куда |
|---|---|
| Оранжевый | SDA Дальнего угла |
| Зелёный | SCL Дальнего угла |
| Синий | SDA Улицы |
| Коричневый | SCL Улицы |
| Все бело-цветные жилы | Общий GND |

Питание участка B разветвляется на VDD и GND обоих датчиков.
Для каждого отвода UTP к отдельному датчику использовать единую схему
из WIRING.md §3.7: оранжевый→SDA, зелёный→SCL, синий→VDD;
их бело-цветные жилы→GND, коричневая пара резервная.
Цвета на стыке назначаются **по сигналу**, а не вслепую цвет к цвету:
например, синий B1 (SDA Улицы) соединяется с оранжевым отвода Улицы.
Заводской четырёхжильный хвост датчика подключается по его паспорту.

## 5. Электрические условия

На каждой шине нужны подтяжки SDA/SCL к 3,3 V. Порядок выбора резисторов,
учёт встроенных подтяжек и ограничения длинных линий — WIRING.md §3.5 и §3.8.
Внутренние подтяжки ESP32 не заменяют расчёт внешних.
У каждого SHT30 требуется 100 нФ между VDD и GND вблизи чипа;
на готовом модуле проверить наличие.

Обе частоты прошивки — 10 кГц. Изоляции отказов по питанию нет:
короткое замыкание общей линии 3V3 может отключить все четыре датчика.
Раздельные SDA/SCL не устраняют эту зависимость.

## 6. Соединения и проверка

Коробки и вводы подобрать под влагу/конденсат и фактические условия.
Клеммы должны допускать материал, тип и сечение жил кабеля.
Каждый провод — в отдельный разрешённый порт; длина зачистки по корпусу
клеммы. Пайку при её выборе изолировать и разгрузить механически.
Универсальной гарантии «пайка надёжнее на много лет» нет.
Кабели датчиков вести отдельно от 230 V.

1. На отключённой и отсоединённой электронике прозвонить каждый маршрут,
   отсутствие КЗ между сигналами, 3V3 и GND; проверить транзит A2→B1.
2. До подключения датчиков измерить полярность и напряжение на концах.
   После подключения проверить VDD на самом дальнем датчике под нагрузкой.
3. На старте получить по одному 0x44 на каждой из четырёх шин в Serial.
   0x45 указывает на другое состояние ADDR и не является рабочим адресом
   текущей конфигурации.
4. Поочерёдно изменить условия около каждого датчика и сверить зону в интерфейсе.
5. Проверить устойчивость всей трассы при работе Wi-Fi и пуске вентилятора.
   Одного успешного сканирования недостаточно; при ошибках проверить
   уровни/фронты осциллографом и ёмкость линии.

Проверка документации не заменяет проверку реальной проводки.
